# Claudex Native Tasks, Compaction, and Tab Resume

## Context
The user wants Claudex to create and continuously maintain Claude Code's native task/todo list, default native auto-compaction to `--autocompact 900000`, and, on a bare interactive `claudex` launch inside Zellij, ask whether to resume the session named after the current tab. They normally rename Claude sessions to match Zellij tabs. Explicit `claudex --resume <chosen-session>` must always override the tab suggestion and bypass its prompt. The current gateway-model session has no task-tracking tools. Official Claude Code documentation explains that unrecognized/custom gateway model names do not receive those tools by default; `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` opts in. The installed Claude Code is 2.1.299 and its help accepts `--autocompact <auto|tokens>` from 100k to 1M tokens.

The actual launcher is `/home/gr33nl4dy/dev/cliproxyapi/runtime/claude-codex`, not code in the current web-switch repository. It currently injects `--autocompact 200000` only when no explicit override appears before `--`, and does not export the task-tool opt-in variables.

## Intended behavior
- Every Claudex work request uses the actual native task list: create or continue a suitable list before substantive work, mark current work in progress, update statuses when work advances, and mark items completed only after verification.
- Resume and compaction continue the existing native list; do not invent an alternative task store, replace it with Markdown, or force unrelated sessions into one global list.
- Native auto-compaction defaults to 900,000 tokens. Explicit `--autocompact VALUE` and `--autocompact=VALUE` continue to take precedence, including `auto`.
- A bare, interactive `claudex` invocation inside Zellij asks `Resume session '<current-tab>'? [y/N]`. Yes forwards `--resume` and the exact tab name to native Claude Code. No/empty/EOF continues normal launch. Resolve the tab by the calling `ZELLIJ_PANE_ID`, never by whichever tab is globally focused.
- Any explicit arguments bypass that prompt, especially `--resume <chosen-session>`, `--continue`, print mode, help, and `--`. Outside Zellij, non-interactive use, missing Zellij, or unavailable tab metadata also skips it. Do not scan session conversations, automatically rename sessions, or silently retry a failed resume as a new session.
- Preserve gateway/model selection, permission settings, unrelated hooks, explicit tool restrictions, and all existing uncommitted/staged work. Do not restart, force-compact, commit, or push without a separate request.
